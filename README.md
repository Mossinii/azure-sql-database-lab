# Laboratório de Azure SQL Database (PaaS)

Registro de estudo sobre uma arquitetura de banco de dados gerenciado no Azure, com tópicos de rede, firewall e consideração de custos.

## Evidência de estudo

A imagem `azure-resource-group-setup.png` mostra uma etapa do portal Azure com o nome do grupo de recursos ocultado. É uma captura de estudo e não representa uma implantação de produção.

## Escopo

Este repositório contém uma descrição textual e uma captura redigida. Não inclui scripts, Infrastructure as Code, configuração implantável, métricas de desempenho ou evidência de execução em produção. Portanto, não representa implantação real, resultado de cliente ou ROI medido.

## Cuidados

Em exercícios reais, use dados fictícios, restrinja regras de firewall às origens necessárias, valide custos antes de provisionar e remova recursos de teste quando não forem mais necessários. Não publique nomes de clientes, projetos internos, endereços, IDs de assinatura ou credenciais.
